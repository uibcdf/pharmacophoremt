# Complete saved-source discovery and inspection

## What and why

Compose public source discovery, exact source/status selection and original work
details in one caller-owned view. A user can choose a source position without
knowing or copying its opaque key beforehand. Global source/work counts and the
full selected intersection remain distinct from the displayed detail prefix.

## How and ownership

One complete cookbook body with five explicit inputs: run path, zero-based source
index, status, positive limit and deliberate legacy admission. Public source/work
iterators and exact-key details retain original order/identity and resource
ownership. Empty/out-of-range source positions print an explicit message. No
runtime helper, API/schema/index, provider operation or molecular grouping.
