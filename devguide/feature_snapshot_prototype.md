## Frozen profile and input domain

The [declaration](../tests/data/feature_snapshot/declaration.json) fixes three
synthetic parents (three ions, isotopic water and a planar six-carbon ring), four
requests and nm/pm application contexts. Independent counts/atom/charge/geometry
witnesses precede execution. All data are original project analytical fixtures;
no chemical dataset is acquired or activity/predictive claim made.

Prepare each parent through public MolSysMT construction and native H5MSM
write/read; explicitly perceive and annotate aromaticity for the ring only. Verify ordered atoms, charges, bonds, one
frame and coordinates within 1e-12 nm; source coordinates remain unchanged. Freeze
artifact bytes/maps/recipe before capture. No alternative parser or preparation
route is chosen after a failure. This is case-specific single-artifact receiving;
MolSysMT#624 collection/snapshot/lifetime support remains unreceived.

Initial wire profile `pharmacophoremt.feature-snapshot-study@1` uses exact UTF-8
canonical finite JSON and a SHA-256-qualified payload. Bounds are 2 MiB encoded,
256 atoms/64 feature occurrences, selection all/frame0/state0 and raw Cartesian
coordinates without imaging. Parent identity is an explicit caller-verified-
artifact/unchanged-source declaration; neither hashes nor the tool authenticate
molecular origin. The producer record identifies only the admitted selected
context, not a complete native/provider build attestation.

Capture calls public `modeler.get_features()` with an explicit effective classical
family set. It retains full detached native recognition/attribution, original
feature/participant/geometry order, requested counts and successful evaluated-empty
families. Unknown root layout, invalid parent/request/frame/state and failed or
partial operations cannot be promoted to successful empty evidence. Actual public
provider failures propagate unchanged.

Known centers, directions/normals and charges use PyUnitWizard QuantityRecord with
field-bound paths and explicit nm/dimensionless/e reader handshakes. Existing
native provenance detachment and public finite-JSON encoding are reused; no local
molecular/quantity codec is added. A frozen bytes-only object owns no live molecule.
Inspection validates structural/schema/canonical-byte integrity, returns original
recorded context and counts, and does not reconstruct scientific quantities or
claim source/geometry verification. Explicit reconstruction validates known
quantity fields and native inventory geometry/maps before reuse. Literal names
remain text. Reading/inspection/reconstruction does not re-extract a source or
credit the original scientific calculation again.
