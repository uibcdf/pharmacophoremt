# Measure native molecular feature reuse

## What and why

The accepted mature0.x plan needs equivalent-work molecular measurements before
choosing a persistent feature cache/index. Existing [equality](../feature_inventory_reuse.md)
demonstrates exact native outputs, not speed. Saved-reader performance is a
different domain and cannot supply this evidence.

## Implemented declaration

The [owning contract](../feature_reuse_measurement.md) and
[prospective plan](../evidence/feature_reuse_profile_plan_20261108.json) fix three
immutable snapshots, four query workloads, four balanced process-order repeats
and48pairs/96timed arms. The standard-library-only declaration tool rejects
schedule/settings/budget drift, invented results and changed snapshot bytes.
No native measurement driver or calculation is qualified. Offline controls and
input hashes do not establish native compatibility or a performance improvement.

## Execution limitation and rejected routes

Current own-user isolation is absent and the last scheduler observation provides
no usable allocation. The native placement route reaches the provider operation
associated with the preserved DATA512MiB/OpenMM import-mapping failure. Do not
retry that exhausted case, silently increase its budget, drop native positive
fits or transfer the old managed-cgroup receiving to this context. Resource
mechanisms stay with infrastructure#1/MolI#96; PHMT owns this workload/evidence.

## Acceptance and continuation

An additional [hosted scope probe](../feature_reuse_measurement.md#hosted-scope-probe-declared-2026-11-08-utc)
is now implemented as a manual-only workflow, with static shell/YAML/Python/lint
checks passing. It has not been executed or received. Its fixed24MiB smoke tests
the standard OS controls in a dedicated managed VM; it imports no molecule or
provider and is separate from the native pilot. Keep local infrastructure and
payload-transfer restrictions explicit; no performance qualification follows.

Receive and verify the declared safe execution scope, exact source/providers/
native artifact, and an actually equivalent shared arm through public tools.
Run the separate two-arm admission pilot before the96timed arms. Retain source
immutability, all native reports, omissions and failures; charge inventory build
cost and compare only equal completed work. Publish all raw samples, uncertainty
scope and the justified next decision, including no benefit. Full library scale,
biological and supported installed/public/platform gates remain separate.

This issue stays open. Independent #108 public-workflow/source coverage can
advance while native execution is unavailable. It is not a reason to stop or
mark the mature0.x goal complete.
