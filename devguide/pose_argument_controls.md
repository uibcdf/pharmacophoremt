# Explicit placed-pose argument controls

Owners LMMV/dprada; selected 2026-11-14 local date. PHMT#214 under partial #6.

## Three independent public operations

`PoseEvaluator.__init__`, `evaluate` and `run` append keyword-only
`skip_digestion=False` to their existing definition-owned ArgDigest contracts.
Default/False calls retain normal argument admission and normalization. Literal
Python True bypasses only the selected operation; NumPy booleans digest and
normalize through the shared host boolean validator. Invalid controls refuse
before query copying, molecular access or borrowed input acquisition.

The shared molecular-database digester declares a named `skip_digestion`
dependency. Public ArgDigest orders that value check before acquiring the reader;
the existing iterable-validation body changes only its value parameter's name to
the canonical `molecular_database`, as required for a multi-argument digester.
Direct positional helper calls
and public native callers without an explicit bound control retain their existing
behavior. Control ordering belongs to the host digester's declared dependency;
no provider change is required.

The constructor and evaluate signatures remain closed. Native run's domain
continues to derive scientific option names from its defining evaluate signature.
Exclude the operation-local control from that forwarded domain and from the
VirtualScreening constructor domains. Each public operation consumes its own
control, including inherited implementations; no bypass propagates to a child.
Existing application evaluate overrides without a skip parameter remain usable.
No method-option union or consumer-side argument engine is introduced.

## Scientific and batch ownership

Keep the constructor/evaluate/run bodies identical except documentation. All
constructor type/quantity/angle/fraction/site/positive-total-weight checks remain.
Native source-frame, finite-coordinate, chemistry, assignment, essential-site,
angular and steric guards retain their owning boundaries during bypass. A skipped
argument refusal can therefore become a native source-stage PoseEvaluationError
with its original cause; bypass is not a promise of identical early error timing.

Keep run's independent default child admission, source occurrence order, batch
pose-ID ownership, on_error policy and failed/unscored denominator. An explicit
run bypass consumes its control locally; empty-batch keyword admission follows
normal public ArgDigest bypass semantics, while batch policy/pose-ID invariants
remain mandatory. Do not silently bypass scientific children or rewrite shared
batch execution. Existing attribution, explicit quantity records and source/
model custody stay unchanged; no new recognition/preparation backend or floor.
