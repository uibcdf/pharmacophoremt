# Choose native ligand consensus through the modeler

`LigandBasedModeler` requires an explicit `consensus_method`: `rigid` fits
prepared ligand frames; `aligned_cliques` consumes a declared common frame.
The class and its list return remain available after retirement of the old
distance-partitioning builder. `n_points` now specifies a minimum site count,
and `min_actives` specifies joint distinct-ligand support, default all inputs.
No conformations or hydrogens are generated by this modeler.

Run this example from the source checkout in the compatible development
environment. The [prepared CCD recipe](prepared_ccd_ligands.md) documents the
original EST/DES ideal SDFs, their hashes and explicit public MolSysMT preparation.
These are two different compounds with declared chemistry and ideal reference
coordinates, not experimental binding poses or an activity benchmark.

```python
import pharmacophoremt as phmt
from pharmacophoremt.modeler import LigandBasedModeler
from pharmacophoremt.validation import summarize_rigid_consensus
from devtools.prepared_ccd_ligands import prepare_case

prepared = {name: prepare_case(name) for name in ('EST', 'DES')}
ligands = [
    {'ligand_id': name, 'molecular_system': item['molecular_system'],
     'structure_index': 0, 'chemical_state': 'reference'}
    for name, item in prepared.items()
]
options = dict(
    consensus_method='rigid', n_points=3, min_actives=2,
    features=['hb acceptor', 'aromatic ring'],
    correspondence_strategy='ranked_triplet_seeds', n_seeds=4,
    refinement_strategy='greedy', orientation_policy='each_step',
    min_matches=3, distance_tolerance='.20 nm',
    direction_tolerance='30 degrees', max_fits=100,
)
modeler = LigandBasedModeler(ligands, **options)
models = modeler.build()
summary = summarize_rigid_consensus(modeler.report)
assert models is modeler.result['models']
assert summary['n_models'] == 1 and summary['max_joint_sites'] == 3
assert summary['n_fits'] == 2 and modeler.result['complete']
assert models[0].score is None
assert set(models[0].metadata['hypothesis']['joint_ligand_ids']) == {'EST', 'DES'}
```

Inspect the complete native report to distinguish accepted placements, geometric
rejections, finite search scope and original sources. Empty evaluated consensus
returns `[]`. Calculation failure or an exhausted search budget raises; it does
not produce a negative result. No legacy RMSD score ranks the returned models.

The high-level entry point delegates to the same modeler. Input selections
belong in each ligand record; one frame is consumed per ligand ID. Conformers
of one compound are not independent supporters.

```python
dispatched = phmt.model(ligands, method='ligand-based', **options)
assert len(dispatched) == 1 and dispatched[0].n_interaction_sites == 3
```

For common-frame discovery select `consensus_method='aligned_cliques'` and use
the applicable options from the [aligned-clique recipe](aligned_cliques.md).
That method performs no fitting. For the full native result without the
historical constructor names, call `from_rigid_ligands()` or
`from_aligned_ligand_cliques()` directly.

Native persistence and optional [scientific attribution](attribution.md) retain
the delegated method's evidence. The facade does not open an Ackredit session;
the application chooses one. The maintained
[migration contract](https://github.com/uibcdf/pharmacophoremt/blob/main/devguide/ligand_based_workflow.md) specifies the
breaking scientific transition and its guards. Environmental hydrogen refinement
for the observed ERα pilot remains a separate MolSysMT #323 dependency.

## Constructor option admission

Options follow the explicitly selected native consensus tool. A rigid-only option
such as max_fits is refused for aligned_cliques before prepared inputs are consumed.
Use n_points/min_actives for the minimum site/support names; min_sites/min_support
are not extra facade options. Unknown names now raise ArgDigest UnknownArgumentError
at this constructor, rather than a delayed native_options error. Application
subclasses keep the defining constructor contract. Explicit skip_digestion=True
retains mandatory method/prepared-input/legacy preparation checks; it does not
generate conformers or relax the scientific method. No new aliases are introduced.
