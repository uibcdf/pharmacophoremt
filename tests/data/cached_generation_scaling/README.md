# Synthetic cached-generation workloads

Frozen before timing under PharmacophoreMT #97. The plan defines typed PHMT
protocol records and numerical hypotheses, not a molecular system or provider
chemical/geometry result. No experimental data, structures, chemical grouping,
preparation or biological labels are used. Repository license applies.

Two donor distances and two distances on each of two ring faces give
`2**donors * 4**rings` alternatives. The independent oracle decodes each ordinal
with mixed-radix arithmetic. Budgets, original cache immutability and every
returned site's geometry/role/choice must agree before interpreting samples.

See `devguide/cached_generation_scaling_protocol.md`. Changes require a new
dated plan and measurement identity, not an update to an old output.
