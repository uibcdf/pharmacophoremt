# Pool-3 capacity metadata

Credit EMBL-EBI ChEMBL_37 for the 475 unmodified activity-ID-only capacity
responses and one status response. They retain the
[ChEMBL CC BY-SA 3.0 terms](https://chembl.gitbook.io/chembl-interface-documentation/about#data-licensing),
separately from the repository software license. The original acquisition journal
retains every URL, response hash/size, timestamp and clean producer.

The declaration was committed before these requests. Responses contain one
activity record ID (or none for an empty source) and pagination/count metadata;
there are no potency values, labels, compound identifiers or structures.
Fifteen assays have at least forty raw records; this is a necessary capacity
condition, not experimental qualification, class balance or molecular independence.
No detailed-table request or molecular calculation is made. Assay nominations
include unsuitable formats such as coactivator experiments. The two earlier
pools and all prior exposure/results retain their original identities.
