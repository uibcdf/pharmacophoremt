hypothesis construction/evaluation. The input is the unchanged archived prepared
ERalpha fragment from #52; no molecular data are duplicated or regenerated here.

ring. The pilot enumerates eight separate two-site pharmacophoric hypotheses
using MolSysMT's cached donor direction and both faces of its aromatic axis.

Independent test-only raw-coordinate vector/plane oracles verify placement and
synthetic feature-pair controls. These feature clouds are not molecular systems,
ligands or binding poses. See the [protocol](../../../devguide/receptor_hypothesis_pilot_protocol.md)
for source custody, enumeration budgets, failure accounting and scientific limits.
