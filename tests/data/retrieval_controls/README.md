# Typed-distance retrieval case

Original project analytical inputs, under the repository MIT license. The frozen
declaration precedes the prototype and execution. No molecular structure, chemical
state, biological label or external dataset is acquired or redistributed.

Eight original #175 families retain their explicit angstrom operands. Extra
occurrences exercise repeated source identities, wrong kinds, collinearity and
#177's numerical candidate band. Exact physical mapping oracles deliberately
exclude that last family. Method, finite sizes, compatibility/incomplete-state
policy and receiving belong to `devguide/retrieval_candidate_controls.md`.
